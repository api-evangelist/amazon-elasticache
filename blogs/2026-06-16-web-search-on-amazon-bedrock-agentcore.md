Web Search on AgentCore is now generally available, enabling agents to ground responses in current web knowledge while keeping data residency within the AWS environment with zero data egress. Built on Amazon's search infrastructure, it combines a web index with structured knowledge graph data and returns excerpts with source URLs and publication dates.
