AWS Glue Data Catalog preview introduces business context and semantic search, letting users enrich tables with glossary terms and custom metadata so the Glue Search API can find data by semantic meaning. MCP-compatible agents including Claude Code and Cursor can connect using the aws-data-analytics plugin from the Agent Toolkit.
