AWS Secrets Manager now offers a secret safety skill in the Agent Toolkit for AWS, enabling agents to securely retrieve and consume secrets without passing secret values through the context window. A two-layer approach steers models away from raw values and resolves secrets only at execution time, so plaintext secrets never appear in context or logs.
