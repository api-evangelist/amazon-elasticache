Amazon Bedrock Guardrails offers InvokeGuardrailChecks API, a new resourceless API that applies individual safeguards at any point in agentic AI applications without creating guardrail resources. It provides granular per-request control, returning numeric severity scores for custom thresholds to block, pass, retry, or log.
