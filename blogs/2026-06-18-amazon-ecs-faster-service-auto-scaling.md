Amazon ECS service auto scaling now detects load changes faster with high-resolution 20-second metrics, improving time to trigger scale-out from 363 seconds to 86 seconds (76% faster). Target tracking policies for CPU and memory utilization support the 20-second resolution alongside the default 60-second option.
