AWS Glue Interactive Sessions now support Apache Spark Connect, enabling development and execution of Spark applications from environments including SageMaker Unified Studio and Jupyter. The thin client architecture decouples the client application from the Spark execution environment for ad hoc exploration and iterative debugging without managing clusters.
