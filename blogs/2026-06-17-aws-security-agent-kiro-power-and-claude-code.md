AWS Security Agent adds support for Kiro and Claude Code, letting developers trigger security scans directly from development environments. Simulated validations execute findings in isolated environments providing proof of exploit, and it integrates with GitLab, GitHub Enterprise, Bitbucket, and Confluence.
