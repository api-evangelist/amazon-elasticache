Customers using Amazon SNS in the Asia Pacific (Seoul) Region can now send text messages to subscribers in more than 200 countries and territories. SMS messaging is available through AWS End User Messaging, with SNS remaining a fully managed pub/sub service for Lambda, SQS, Data Firehose, mobile devices, and email.
