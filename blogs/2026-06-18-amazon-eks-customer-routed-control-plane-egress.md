Amazon EKS introduces customer-routed control plane egress, allowing outbound Kubernetes API server traffic through customer VPCs, including admission webhook callbacks, OIDC provider lookups, and aggregate API server requests. It is available at no additional cost in all AWS Regions where EKS operates.
