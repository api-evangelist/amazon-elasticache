AWS announces Continuum, which discovers, prioritizes, validates, and remediates security risks at machine speed within defined guardrails. For code vulnerabilities in gated preview it ingests findings, prioritizes using context graphs, and validates exploitability in sandboxes; Continuum threat modeling generates threat models in STRIDE format from design documents or source code.
