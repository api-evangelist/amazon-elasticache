AWS Security Agent, now part of AWS Continuum, includes a threat modeling capability in public preview that automatically generates threat models by analyzing design documents or source code and identifying threats with recommended mitigations using the STRIDE framework. Developers integrate it into IDEs like Kiro and Claude Code.
