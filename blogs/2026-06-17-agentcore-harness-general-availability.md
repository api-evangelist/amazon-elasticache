The managed agent harness in Amazon Bedrock AgentCore is now generally available, handling orchestration, tool execution, context management, and state persistence to replace manual loop coding. Customers define agents through configuration specifying model, tools, skills, and instructions, and AgentCore assembles production-grade agents with isolated environments, filesystem, and memory.
