Oracle Database@AWS now supports Oracle Autonomous AI Database Serverless, a fully managed Oracle database service on Exadata infrastructure that automatically handles patching, tuning, and scaling. Available through AWS Marketplace with BYOL or License Included options, it supports four workload types with independently scaling compute and storage.
