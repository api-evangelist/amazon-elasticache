Amazon MQ for RabbitMQ now supports private networking, enabling brokers to connect to private VPC resources without public exposure, including RabbitMQ Federation, Shovel, and private LDAP and OAuth 2.0 providers. Amazon VPC Lattice, AWS Resource Access Manager, and AWS PrivateLink manage the infrastructure, removing prior Network Load Balancer and NAT Gateway workarounds.
