Amazon CloudWatch Synthetics now supports multilocation canaries, letting developers run the same canary across multiple AWS Regions simultaneously and consolidate all run data, metrics, and artifacts in the primary Region. Replica canaries run independently to help identify region-specific bottlenecks and validate third-party dependencies.
